# C++ and HTML/CSS Dice Rolling Game

A lightweight, interactive desktop dice rolling application powered by a modern C++ backend and an HTML/CSS/JavaScript web interface.

## 🚀 Features
- **Modern UI:** Clean, dark-themed design with smooth CSS rolling animations.
- **C++ Backend:** Uses C++11 `<random>` library (`std::mt19937`) for secure pseudo-random number generation.
- **No Heavy Dependencies:** Runs entirely using a standard web browser and a lightweight compiled C++ executable.

## 📁 Project Structure
- `index.html` - Contains the frontend design, layout, and JavaScript logic.
- `main.cpp` - Contains the C++ random dice rolling logic.
